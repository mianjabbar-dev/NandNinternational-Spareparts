# Image Source Manifest

All product photographs on this website are **real photographs of real
automotive components**, downloaded from Wikimedia Commons and stored
locally in `public/images/products/`. The website does not hotlink or
load any image from an external server at runtime.

Every source below carries an explicit free license (Creative Commons,
CC0, or Public Domain) as recorded on its Wikimedia Commons file page at
the time of download (21 October 2026). Attribution is given here and in
a photo-credits note in the website footer, as the licenses require.
No retailer screenshots, no price/promotional imagery, and no
AI-generated product images are used.

## Modifications made to downloaded files

Only resizing and cropping were applied, which the licenses permit.
No product was altered, composited, or replaced:

- Most files were downloaded at a 1280 px-wide rendition of the
  original and saved as quality JPEGs to keep page weight reasonable.
- Front disc brake pads image: cropped to focus on the pad being held
  against the rotor.
- Brake disc rotor image: cropped from the original wide shot to focus
  on the front disc brake and caliper (also used in the hero section).
- All final files are stored as JPEGs in `public/images/products/`.

## Notes on selection

- Each image was visually verified to depict the named automotive
  component. Several initially downloaded candidates were rejected
  after visual inspection (for example: bicycle disc brake pads, a
  motorcycle brake-pad collage, a labeled alternator textbook diagram,
  and a vintage gearbox line drawing) and replaced with verified
  automotive photographs listed above.
- Source file titles sometimes name a specific vehicle the photographed
  component was fitted to or taken from. The website itself makes **no**
  vehicle-compatibility, OEM, stock, or availability claims — the
  photographs are presented as examples of each component type.
- There are **no unresolved licensing issues**: every image in the
  project has an explicit free license recorded above.
